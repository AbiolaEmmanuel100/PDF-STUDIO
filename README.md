# PDF Studio — Local Adobe Acrobat Alternative

A fully client-side PDF toolkit that runs entirely in your web browser.  
**No installation. No server. No uploads. Your files never leave your device.**

## Features

- **Merge** multiple PDFs (with reordering via ↑↓ buttons)
- **Split / Extract** specific pages or ranges
- **Rotate** pages (90°, 180°, 270°)
- **Convert Images → PDF** (JPG, PNG, etc.)
- **Convert DOCX → PDF** (basic formatting)
- **Create PDF from plain text**
- **Stamp / overlay text** (watermarks, “CONFIDENTIAL”, etc.)
- **Inspect PDF** (page count, metadata) + **live preview** + extract text

## How to Use

1. Download and unzip the folder.
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari recommended).
3. Use the tabs to choose a tool.
4. **Click the dashed box** or drag-and-drop files into it.
5. Process and download the result.

If the file dialog does not open when you click the box, try dragging the file onto the box instead. Everything happens locally.

## Tips

- Live page previews appear after you load a PDF in Split, Rotate, Stamp, and Info tabs.
- For complex Word documents with heavy formatting, LibreOffice (free) usually gives better results.
- Scanned PDFs (image-only) won’t have extractable text unless OCR is applied separately.
- Large files may use more memory — modern browsers handle most everyday documents fine.

Enjoy your private, local PDF studio!
